# Университет: Электрондық журнал (Pro)

## Іске қосу
    pip install -r requirements.txt
    streamlit run app.py

Әдепкі әкімші: `admin` / `admin123` (бірінші кіргенде парольді өзгертіңіз).
Парольді `ADMIN_PASSWORD` орта айнымалысымен беруге болады (тек бірінші құрылғанда).

## Құрылымы
    app.py              кіру нүктесі, рөл бойынша бағыттау
    core/
      config.py         тұрақтылар, баптаулар
      schema.py         кестелер құрылымы
      database.py       қосылым, db(), query_df(), init_db()
      security.py       PBKDF2 хэштеу
      audit.py          аудит логы, кіруді шектеу
      gpa.py            GPA есептеу
      ui.py             стильдер, esc(), flash(), stat_card()
    views/
      auth.py           кіру / студентті тіркеу
      common.py         бүйір мәзір, парольді өзгерту, ескертулер
      profile.py        профиль беті (барлық рөлге)
      admin.py          әкімші беттері
      teacher.py        оқытушы беттері
      student.py        студент беттері

## Жаңа бет қосу
Тиісті `views/<рөл>.py` файлында функция жазып, `PAGES` сөздігіне қосыңыз —
мәзірде автоматты түрде пайда болады.

## Дизайн
- Қарип: Manrope (Google Fonts, интернет қажет; болмаса жүйелік қаріп қолданылады).
- Барлық стиль `core/ui.py` ішіндегі `STYLES` айнымалысында, түстер `:root` ішінде.
- Тема `.streamlit/config.toml` файлында (жарық тема мәжбүрленген).
